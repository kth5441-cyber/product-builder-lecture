# 05 - 핵심 개념 정리

이 프로젝트로 짚을 수 있는 웹 개발 핵심 개념들입니다.

## 관심사 분리

구조(HTML) · 표현(CSS) · 동작(JS)을 각각 다른 파일로 나눕니다.
서로 독립적이라 유지보수와 협업이 쉬워집니다. → [[01 - 파일 구조#각 파일의 책임 (관심사 분리)]]

## DOM 조작

JS가 `getElementById` 로 요소를 찾고, `createElement` / `appendChild` 로
새 요소를 만들어 붙입니다. 화면은 "데이터 → DOM" 으로 그려집니다.
→ [[04 - JavaScript 로직#displayLottoNumbers]]

## 이벤트 기반 프로그래밍

`addEventListener('click', ...)` 로 사용자의 행동(클릭)에 반응합니다.
프로그램이 위→아래로만 흐르지 않고, **이벤트가 올 때** 동작이 실행됩니다.

## Set 으로 중복 제거

`Set` 은 같은 값을 두 번 담지 않습니다. 로또처럼 "중복 없는 N개"를 만들 때 유용합니다.
`while (set.size < 6)` 로 6개가 찰 때까지 반복합니다. → [[04 - JavaScript 로직#generateLottoNumbers]]

## CSS 변수

`--변수명` 으로 값을 정의하고 `var(--변수명)` 으로 씁니다.
테마별로 변수만 바꾸면 전체 색이 한 번에 바뀝니다. → [[03 - CSS 스타일링]]

## 상태 저장 (localStorage)

`localStorage` 는 브라우저에 데이터를 문자열로 저장합니다(새로고침해도 유지).
여기서는 선택한 테마를 기억하는 데 씁니다. → [[04 - JavaScript 로직#initTheme]]

## 반응형 디자인

`@media (max-width: ...)` 로 화면 크기에 따라 다른 스타일을 적용합니다.
→ [[03 - CSS 스타일링#반응형]]
