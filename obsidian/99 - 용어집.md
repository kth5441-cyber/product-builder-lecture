# 99 - 용어집

프로젝트에 나오는 용어를 한 줄로 정리했습니다.

- **DOM (Document Object Model)** — HTML 문서를 JS가 다룰 수 있게 만든 객체 트리. → [[05 - 핵심 개념 정리#DOM 조작]]
- **이벤트 리스너 (Event Listener)** — 클릭 등 특정 사건이 일어날 때 실행할 함수를 등록하는 것.
- **Set** — 중복을 허용하지 않는 값들의 모음(자료구조). → [[04 - JavaScript 로직#generateLottoNumbers]]
- **CSS 변수 / 커스텀 프로퍼티** — `--이름` 으로 정의하고 `var(--이름)` 으로 쓰는 재사용 값. → [[03 - CSS 스타일링]]
- **data 속성 (`data-theme`)** — HTML 요소에 상태를 담아두는 사용자 정의 속성. CSS·JS가 함께 활용.
- **localStorage** — 브라우저에 데이터를 영구 저장하는 저장소(문자열). → [[05 - 핵심 개념 정리#상태 저장 (localstorage)]]
- **미디어 쿼리 (`@media`)** — 화면 조건에 따라 다른 CSS를 적용하는 규칙. → [[03 - CSS 스타일링#반응형]]
- **키프레임 (`@keyframes`)** — 애니메이션의 시작·끝(중간) 상태를 정의하는 CSS 규칙.
- **인라인 스타일** — 요소의 `style` 속성으로 직접 지정하는 스타일. 여기선 공 배경색에 사용.
- **위키링크 (`[[ ]]`)** — Obsidian에서 노트끼리 연결하는 문법. 이 볼트 전체가 이걸로 이어져 있습니다.
