# 📒 Obsidian 참조 노트 (Obsidian Reference Notes)

이 `obsidian/` 폴더는 **product-builder-lecture**(로또 번호 생성기 웹앱)를
Obsidian 마크다운 볼트(vault) 형식으로 정리한 참조 자료입니다.
강의에서 프로젝트 구조·코드·개념을 빠르게 찾아볼 수 있도록 구성했습니다.

## 사용 방법

1. Obsidian을 열고 **"폴더를 볼트로 열기(Open folder as vault)"** 로 이 `obsidian/` 폴더를 엽니다.
2. [[00 - 프로젝트 개요]] 노트부터 시작하세요. 나머지 노트로 이어지는 링크가 있습니다.
3. 노트 사이의 `[[위키링크]]` 를 클릭해 이동하고, **그래프 뷰(Graph View)** 로 연결 관계를 확인하세요.
4. 상단의 `#태그` 로 관련 노트를 묶어서 볼 수 있습니다.

- [[03 - CSS 스타일링]] — `style.css`, 테마 변수, 반응형

- [[99 - 용어집]] — 자주 나오는 용어 정의
