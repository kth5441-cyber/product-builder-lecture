# 00 - 프로젝트 개요

## 무엇을 만드나요?

**Lotto Number Generator** — 버튼을 누르면 **1~45 사이의 서로 다른 6개 숫자**를
무작위로 뽑아 로또 공(ball) 모양으로 예쁘게 보여주는 웹 페이지입니다.

원본 기획 문서는 저장소 루트의 `blueprint.md` 이며, 이 노트는 그 기획을 구현한 결과를 설명합니다.

## 핵심 기능

- 🎱 **번호 생성** — 중복 없는 6개 숫자를 오름차순으로 정렬해 표시
- 🎨 **색상 규칙** — 실제 로또처럼 숫자 구간별로 공 색을 다르게 (→ [[04 - JavaScript 로직#getLottoColor]])
- 🌙 **다크 모드** — 라이트/다크 테마 토글, 선택은 `localStorage` 에 저장
- 📱 **반응형** — 모바일에서도 레이아웃이 무너지지 않음 (→ [[03 - CSS 스타일링#반응형]])

## 사용 기술

순수 웹 기본 3종만 사용합니다. 프레임워크·빌드 도구 없음.
